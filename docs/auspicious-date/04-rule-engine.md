# Rules

Handlers are backend-only identifiers. Initial draft: DIRECT_AGE_CONFLICT, BRANCH_HARMONY, TRADITIONAL_TABOO, AUSPICIOUS_DAY. All require verified sources before publication. Optional PURPOSE_OFFICER uses explicit approved officer indices; FIVE_ELEMENT_RELATION uses nap-am, not guessed zodiac element.

CRITICAL hard exclusion always AVOID. Score starts 50, clamp 0–100. VERY_GOOD requires >=80 and at least two positives/no high negative; GOOD >=65 with positive/no high negative; NOT_RECOMMENDED high negative or score<40; otherwise NORMAL. Stable sort: classification, critical count, score desc, date asc. These thresholds are product policy, not traditional claims.

Unsupported 28 Tú/cát thần/hung thần: interfaces only, null/unavailable; no invented source or result. Almanac rules use lunar month/year boundary, Vietnamese timezone. Nạp âm 60-cycle data; trục/hours conventions documented in code and source verification required.
