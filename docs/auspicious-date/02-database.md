# Database

7 bảng mới: auspicious_date_settings (singleton), auspicious_rule_sets (purpose/version/revision/validation), auspicious_rules (registry identifier), auspicious_rule_contents, auspicious_rule_sources, auspicious_reference_cases, auspicious_change_logs.

FK rule -> set; contents/sources -> rule; cases -> set; audit -> profile. One published ruleset per purpose enforced by partial unique index. Content/source/reference cloned with version; published immutable. Audit không có update/delete API.

Migration generated by drizzle-kit; validate with PGlite. Không tự migrate production. Seed idempotent, disabled settings + DRAFT foundational rules, no fake reference results. Permissions additive.
